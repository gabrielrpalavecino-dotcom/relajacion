# Juegos para Calmar la Ansiedad (Switch-like)

App estilo Nintendo Switch con:
- 4 usuarios (Papa, Mama, Romeo, Avril)
- Progreso por usuario en la nube (GitHub)
- Misiones diarias
- Explicaciones y acciones por tip

## Variables de entorno

Configurar en el hosting:

- `GITHUB_TOKEN`
- `GITHUB_USER`
- `GITHUB_REPO`

## Deploy

- Subir el repo a GitHub.
- Conectar a Netlify/Vercel.
- Configurar env vars.
- Listo: cada usuario guarda y carga su progreso desde GitHub.
